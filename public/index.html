About This Project

The Online Rental Property Management System is a B.Sc. Computer Science final year project from Obong University, designed to centralize and streamline rental property operations.

Built with modern web technologies including Node.js, MongoDB, and Tailwind CSS, this system provides a complete solution for property listing, tenant management, lease tracking, rent payment recording, and maintenance request handling.
